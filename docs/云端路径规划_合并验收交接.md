# 知行云端路径规划合并验收

路径规划主流程已经实现。当前处于云端验收和缺口收尾阶段。学生端学习后的重规划效果仍需通过一次真实的前后测验证。

## 本次合并内容

| 模块 | 实现与优化 |
| --- | --- |
| 目标与课程 | 支持课程目录、知识点和先修关系，结合目标、诊断和可用资料确定学习范围。 |
| 库外目标 | 支持千问联网搜索，保存网页原文摘录与来源。活动和引文分开核对，证据不足时保留缺口。 |
| 补练 | 首轮审查发现缺口时尝试生成补练。支持格式纠错、剩余额度内的定向补搜及逐项复核记录。 |
| 二分查找 | 区分命中和未命中，校验索引与逐轮区间。双缺口补练使用同一升序数组，展示命中索引和完整未命中推演。 |
| 排期 | 根据周预算和截止日期分配每日时长，目标审核齐全后默认保留核心活动与先修。 |
| 其他 | 包含完整运行所需的前后端源码、数据库迁移、静态课程数据和测试。运行数据库、账号和模型密钥留在本机。 |

## 合并约定

本次候选分支基于个人仓库远端主分支 `2f8d2a8`。合并前核对目标仓库的迁移历史。候选版本的迁移链至 `0031_discovery_drafts`。旧迁移链的 `0019` 和 `0020` 与候选版本使用相同编号但内容不同。已有业务数据库应先备份，再在副本上检查迁移版本和表结构。首次验收使用空数据库。题库模块如有队友并行改动，先逐文件合并题库、诊断及相关迁移，再运行验收。

## 复测步骤与通过标准

1. 使用仓库 README 的安装步骤和项目虚拟环境。设置 `PYTHONPATH=backend` 后运行 `python -m pytest backend/tests/test_discovery_drafts.py backend/tests/test_cloud_evidence.py -q`。隔离候选版本已通过这 37 项测试。
2. 本机启动云端搜索服务，使用验收学生创建目标“用二分查找在已排序数组中定位目标，并用一个不存在的目标验证返回结果”。核对正确的命中索引和未命中返回值，确认每轮区间都展示在学生可见的正文里，且核心活动进入排期。最新正式版第 34 轮仍为 `partial`，双缺口修正待真实复测。
3. 创建四元数旋转目标。验证实部位置一致，绕 z 轴旋转 90° 后 `(1,0,0)` 变为 `(0,1,0)`，两个长度均为 1，检查旋转与长度验证的引文和排期。此前补练已进入排期，旋转引文还需要收尾。
4. 用未提供的本班评分细则建目标，核对系统提示提供资料正文，且不会生成分数。该负例已在正式版通过。
5. 完成诊断、学习记录和前后测，再发起重规划，核对新增证据是否改变后续活动。保留运行记录和结果作为验收证据。
